# Welcome to superstats!

`superstats` provides tools for neural superstatistics: Bayesian estimation of
time-varying parameters in dynamic cognitive models with amortized inference.

The documentation is organized around the same split used by mature scientific
Python projects: a short path to first use, conceptual guide material, runnable
examples, and an API reference generated from the package docstrings.
